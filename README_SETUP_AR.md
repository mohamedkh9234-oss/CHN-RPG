# دليل نشر لعبة Community Health Nursing RPG مجانًا

## النسخة الحالية
- لا يوجد تسجيل دخول أو اسم مستخدم أو كلمة مرور.
- التقدم يُحفظ تلقائيًا على نفس الجهاز والمتصفح باستخدام `localStorage`.
- لا توجد قاعدة بيانات ولا حفظ سحابي ولا حاجة إلى Firebase.
- `admin.html` محرر مجاني لتعديل محتوى الدروس والأسئلة الموجودة، ويصدر ملف `content.json`.
- `content.json` ملف اختياري لتحديث الدروس والأسئلة. لا ترفع بيانات شخصية أو درجات طلبة إليه؛ محتوى مستودع GitHub العام يراه الجميع.
- Google Analytics اختياري. يظل معطلًا افتراضيًا. يمكنك ترك `G-REPLACE_ME` كما هو وعدم إعداد Analytics الآن.

## الخطوة 1: نزّل الحزمة وفك الضغط
نزّل `CHN_RPG_Free_Deployment_Pack.zip` ثم فك ضغطه على جهازك. ستجد `index.html` و`admin.html` و`content.json` وهذا الدليل.

## الخطوة 2: افتح مستودع اللعبة الحالي
1. افتح: https://github.com/mohamedkh9234-oss/ZY-ACADEMY-
2. سجّل الدخول إلى GitHub إذا طُلب منك.
3. قبل استبدال أي شيء، يمكنك فتح ملف `index.html` الحالي والاحتفاظ بنسخة احتياطية منه على جهازك.

## الخطوة 3: ارفع النسخة الجديدة
1. من صفحة المستودع اضغط **Add file** ثم **Upload files**.
2. ارفع الملفات التالية من المجلد الذي فككت ضغطه: `index.html` و`admin.html` و`content.json` و`README_SETUP_AR.md`.
3. انتظر حتى تظهر الملفات في قائمة الملفات.
4. في أسفل الصفحة اكتب رسالة مثل `Publish local-save student game` ثم اضغط **Commit changes**.
5. لا ترفع `firestore.rules`؛ لم نعد نستخدم Firebase أو Firestore في هذه النسخة.

## الخطوة 4: تأكد من إعداد GitHub Pages
1. في المستودع افتح **Settings** ثم **Pages**.
2. تحت **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save** إذا لم يكونا محددين بالفعل.
4. انتظر دقيقة أو بضع دقائق، ثم افتح رابط اللعبة:
   https://mohamedkh9234-oss.github.io/ZY-ACADEMY-/
5. جرّب فتح الرابط في نافذة خاصة أو اعمل تحديثًا قويًا للصفحة حتى لا تظهر نسخة قديمة مخزنة مؤقتًا.

## الخطوة 5: اختبرها قبل إرسالها للطلبة
- افتح رابط اللعبة من الهاتف والكمبيوتر.
- اختر آدم أو مريم واضغط **ابدأ الاستكشاف**.
- أكمل جزءًا من مهمة أو سؤالًا، ثم أغلق الصفحة وافتح الرابط مرة أخرى من نفس المتصفح والجهاز؛ ينبغي أن يعود التقدم المحفوظ.
- جرّب متصفحًا آخر أو جهازًا آخر: من الطبيعي أن يبدأ التقدم من جديد، لأن الحفظ محلي وليس سحابيًا.
- إذا لم تعمل اللعبة، تأكد من الإنترنت لأن مكتبة الرسوم ثلاثية الأبعاد تُحمّل من الإنترنت، ثم أعد تحميل الصفحة.

## الخطوة 6: إرسال الرابط للطلبة
بعد نجاح الاختبار، أرسل الرابط التالي للطلبة:
https://mohamedkh9234-oss.github.io/ZY-ACADEMY-/
لا يحتاج الطالب إلى تثبيت تطبيق أو إنشاء حساب. يُفضّل أن يستخدم نفس المتصفح دائمًا وألا يمسح بياناته إذا أراد الاحتفاظ بتقدمه.

## تعديل المحاضرات والأسئلة لاحقًا
1. افتح `admin.html` من رابط الموقع، أو افتح الملف محليًا في المتصفح.
2. ارفع ملف `content.json` الحالي داخل المحرر أو ابدأ بالنموذج الفارغ.
3. عدّل الدروس والأسئلة، ثم اضغط **فحص الملف** وبعدها **تنزيل content.json**.
4. ارفع `content.json` الجديد إلى مستودع GitHub بنفس خطوات الخطوة 3، ثم اضغط **Commit changes**.
5. بعد تحديث الموقع افتح اللعبة واختبر التعديلات.

المحرر يدعم تعديل نصوص وبنوك أسئلة المهمات الموجودة فقط، مثل `community` و`school` و`phc` و`mch` و`women`. إضافة شخصية أو مبنى أو مهمة جديدة تحتاج تعديل كود اللعبة.

## ملاحظات مهمة
- الحفظ المحلي لا يزامن التقدم بين الأجهزة، وقد يضيع عند مسح بيانات الموقع أو تغيير المتصفح.
- لا تضع أي معلومات شخصية عن الطلبة داخل `content.json`.
- لا تحتاج إلى إعداد Firebase أو ربط بطاقة دفع.
- لو أردت إحصائيات زيارات باستخدام Google Analytics 4 لاحقًا، أنشئ Web data stream وخذ Measurement ID الذي يبدأ بـ `G-`، ثم استبدل `G-REPLACE_ME` بقيمة المعرّف في `index.html`. هذا اختياري، ويمكن نشر اللعبة بدونه.
