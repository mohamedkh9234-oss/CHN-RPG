لوحة إدارة محتوى Community Health Nursing RPG

استخدمها لإعداد أو تعديل المحاضرات والأسئلة ثم تنزيل ملف content.json ورفعه بجانب index.html في مستودع GitHub Pages.

مهم: هذه أداة تحرير محلية مجانية، وليست لوحة نشر سحابية محمية. لا تضع فيها بيانات طلبة أو كلمات مرور. أي محتوى تنشره داخل مستودع عام سيكون متاحًا للزوار.

1) استيراد المحتوى

لم يتم تحميل ملف بعد. ابدأ بتحميل النموذج أو ارفع ملف content.json موجودًا.

2) محرر JSON

يمكنك تعديل الدروس والأسئلة في المحرر. استخدم فقط معرّفات المهمات الموجودة في اللعبة، مثل community وschool وphc وmch وwomen. كل سؤال: نص السؤال، قائمة الاختيارات، رقم الإجابة الصحيحة بدءًا من صفر، ثم تفسير اختياري.

3) نشر التعديلات مجانًا

  1. اضغط «فحص الملف» ثم «تنزيل content.json».
  2. افتح مستودع اللعبة على GitHub، واضغط Add file ثم Upload files.
  3. ارفع content.json إلى نفس المجلد الذي يحتوي index.html ثم اضغط Commit changes.
  4. بعد تحديث GitHub Pages، ستقرأ اللعبة المحتوى المنشور تلقائيًا عند فتحها.

تعديل النصوص والأسئلة الحالية مدعوم. إضافة مبنى أو شخصية جديدة أو مسار مهمة جديد تتطلب تعديلًا برمجيًا للعبة.
